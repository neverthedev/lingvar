# Модель обучения: правила, прогресс и повторение

Дата фиксации: 2026-09-12.

Статус: основная продуктовая модель согласована с владельцем продукта.
Неоднозначность оценки составных ответов признана; способ её разрешения пока
не выбран. Предложения и открытые вопросы ниже не являются утверждённым
алгоритмом или технической спецификацией.

## Назначение и границы

Lingvar — приложение для изучения польского языка через разнообразные упражнения,
повторение слов и грамматики, с индивидуальным отслеживанием прогресса.
Ближайшая версия предназначена для небольшой группы учеников.

Этот документ фиксирует модель освоения грамматики. Отдельную модель знания
значений слов предстоит уточнить; её нельзя автоматически приравнивать к знанию
грамматических форм.

В текущий объём входят текстовые упражнения. MP3, YouTube и задания, для выполнения
которых требуется аудио или видео, в этот объём не входят.

При расхождениях с [исходными требованиями](../CUSTOMER_REQUIREMENTS.md) этот
документ имеет приоритет в перечисленных вопросах.
Состав команды и порядок работы зафиксированы в [процессе разработки](DEVELOPMENT_PROCESS.md),
принятые решения — в [списке действующих решений](DECISIONS.md).
План, календарные сроки и окончательный объём первой версии будут определены отдельно.

## Согласованная основная модель

### Иерархия правил

Центральная сущность — правило, состоящее из нескольких частей. Части могут
делиться дальше, образуя иерархию. Группы случаев и исключения должны быть
представлены достаточно подробно, чтобы их можно было тренировать и оценивать
по отдельности.

Пример владельца продукта — множественное число niemęskoosobowy:

- верхний уровень объединяет правило образования множественного числа;
- внутри выделяются ветви по роду;
- внутри ветвей — группы по окончаниям и другим условиям применения;
- исключения выделяются так, чтобы знание общих случаев не подменяло их освоение.

Это пример структуры, а не завершённая грамматическая классификация. Точный
состав ветвей, формулировки условий и место каждого исключения требуют отдельной
проработки по учебным материалам.

### Упражнения и блоки

Ученику можно предложить блок на верхнеуровневое правило. Задания внутри блока
проверяют разные части этого правила. Результаты учитываются отдельно по частям,
а не только как общий балл за блок.

Урок или тематический текст служит контекстом и способом группировки заданий.
Прогресс одной и той же части правила должен сохраняться между разными уроками,
словами и форматами упражнений. Последовательное прохождение
«тема → объяснение → практика» не является обязательной основой продукта.

Существующие таблицы спряжения глаголов и склонения существительных — часть
будущего набора форматов. Разнообразие упражнений должно расширяться.

### Персональный прогресс и время

Для каждого ученика оценивается, насколько хорошо он помнит каждую проверяемую
часть правила. Успехи в одной части не означают освоение соседних частей.
Родительское правило показывает сводку по дочерним частям; способ вычисления
сводки ещё предстоит определить.

Без повторения текущая оценка запоминания части правила должна снижаться.
История фактических ответов при этом сохраняется: снижение оценки не превращает
прошлый правильный ответ в ошибочный.

Нужно различать отсутствие данных о части правила и ухудшение текущей оценки
после перерыва. Конкретные шкала, формула снижения, интервалы и пороги освоения
пока не выбраны.

### Подбор следующих заданий

Система предлагает задания на наименее освоенные или давно не повторявшиеся
части правил. Сначала определяется потребность в повторении частей, затем
подбираются подходящие задания и контекст.

Выбор большого правила учеником и предложенная системой тренировка используют
один персональный прогресс. Баланс слабых частей, повторений и нового материала
предстоит определить отдельно.

## Открытый вопрос: ответ проверяет несколько правил

### В чём неоднозначность

Одно предложение, один пропуск или одно словосочетание может одновременно
проверять несколько частей одного правила либо несколько разных правил.
Например, в ответе со словосочетанием могут проверяться форма существительного
и согласование прилагательного. Выбор глагола по смыслу и образование его формы
также могут влиять на один ответ.

Общая отметка «неверно» не показывает, какое именно знание отсутствует. Даже
правильный ответ сам по себе не определяет, насколько следует повысить оценку
каждого задействованного правила.

Владелец продукта подтвердил наличие этой проблемы. Не принято решение
автоматически повышать или снижать прогресс всех правил, связанных с предложением.
